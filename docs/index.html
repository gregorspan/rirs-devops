Todo aplikacija z FastAPI backendom in Next.js frontendom

Člani ekipe

Gregor Span

Opis projekta

RIRS DevOps je moderna todo aplikacija, ki omogoča upravljanje opravil z intuitivnim uporabniškim vmesnikom. Projekt je sestavljen iz dveh glavnih komponent:

Backend (FastAPI): RESTful API, ki omogoča upravljanje todo elementov. API podpira osnovne CRUD operacije in zagotavlja robustno rešitev za shranjevanje in upravljanje podatkov.

Frontend (Next.js): Sodoben spletni vmesnik, zgrajen z Next.js in shadcn/ui komponentami. Aplikacija omogoča enostavno dodajanje, urejanje in brisanje opravil z real-time posodobitvami.

Projekt uporablja CI/CD pipeline z GitHub Actions za avtomatizirano testiranje, gradnjo Docker slik in uvajanje v različna okolja (Development in Production).

Tehnologije

FastAPI Next.js TypeScript Python Docker GitHub Actions shadcn/ui Vitest Pytest
